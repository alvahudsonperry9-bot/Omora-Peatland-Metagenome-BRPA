## Computational Environment

The bioinformatics workflow was executed on a workstation equipped with an **Intel Core i9-14700K processor**, **128 GB of DDR5 5600 MHz RAM**, an **NVIDIA Tesla V100 12 GB GPU**, and **20 TB of total storage**. The storage was organized as follows:

* **2 × 8 TB HDDs** — raw sequencing data and processed data.
* **2 × 1 TB SATA SSDs** — operating system and software environments, running **Ubuntu 24.04.3 LTS**.
* **2 × 1 TB PCIe NVMe SSDs** — databases and other high-I/O resources used by the bioinformatics workflow.

This hardware configuration was used for sequence processing, metagenomic assembly, genome binning, genome quality assessment, taxonomic classification, and downstream functional analyses.
